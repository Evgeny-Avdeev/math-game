# Считай легко

Детский тренажёр сложения и вычитания двузначных чисел.

Четыре мира: космос (звёзды и 36 артефактов), собаки (Лорри — мальтипу, косточки и 36 пород), кошки (сосиски и 36 пород), футбол (мячи и 36 карточек игроков). Все тренировки и миссии смешивают сложение и вычитание. Каждый мир сохраняет отдельный прогресс в браузере. Старый космический прогресс сохраняется.

Статический сайт без сборки. GitHub Pages: main, / (root). Для локального запуска используйте HTTP-сервер.

Футбол: четвёртый мир с мячами и 36 карточками известных футболистов. На карточках индивидуальные векторные иллюстрации игроков, страна, позиция и короткие биографии.

У каждого мира свой аватар. Доступны 12 значков за примеры, серии ответов, приключения и коллекции; прошлый прогресс учитывается.

## Деревья и палатки

Встроенный раздел с 72 уникальными заданиями: по 24 поля 5×5, 6×6 и 8×8. Каждое имеет единственное решение. Интерактивный учебный лагерь объясняет правила без начисления наград. Палатки, трава, ластик, отмена, подсказки и проверка правил с взаимно однозначным сопоставлением деревьев и палаток. За новое решённое поле — следующая карточка выбранного набора и 10 единиц валюты мира. Повторная награда за то же поле в этом мире не выдаётся. Статистика примеров не увеличивается. Старые сохранения совместимы. Незаконченные лагеря сохраняются отдельно для каждого набора в каждом мире. Размер и очередное задание назначаются автоматически.

Проверка: `node --test tests/tents.test.mjs`.

### Единый сбор коллекции

Вкладка «Играть» открывает общую цель выбранного мира. В панели под ней выбирается набор карточек и занятие: примеры или «Деревья и палатки». Оба занятия открывают следующую карточку одного выбранного набора. Карточки миссий выбирают набор и возвращают к общей панели занятий. Внутри головоломки набор уже задан общей целью; отдельного выбора коллекции там нет. Прежние награды и поля сохраняются.

### Сложность по набору

Размер поля задаётся порядком набора в каждом мире: 1 → 5×5, 2 и 3 → 6×6, 4 → 8×8. Ручного выбора размера и номера нет. Игра выдаёт первую ещё не решённую головоломку нужного размера по порядку. Для второго и третьего наборов используется общая последовательность 6×6 без повторных наград. Начатые поля сохраняются отдельно по наборам. Старое поле переносится, если соответствует набору и следующему заданию. Когда все поля размера решены, они повторяются для тренировки без повторной награды.

Правильная расстановка палаток автоматически завершает лагерь и выдаёт награду один раз. Кнопка «Проверить» сохраняется для объяснения ошибок. Над полем показано, сколько палаток осталось поставить; лишние палатки выделяются красным.

Нажатие на клетку циклически меняет её состояние: пусто → палатка → трава → пусто. Отдельных кнопок инструментов нет. Отмена хода и автоматическое завершение сохранены.


## Посещаемость

Необязательный модуль `analytics.mjs` отправляет посещения, выбор мира, начало и завершение игр на `/analytics/collect` сервиса https://schitay-legko.evgeny-e-avdeev.chatgpt.site. Сама игра остаётся на GitHub Pages. Ошибки загрузки и отправки статистики не блокируют игру.

Страница владельца: https://schitay-legko.evgeny-e-avdeev.chatgpt.site/analytics. Отчёт и API проверяют личность владельца на сервере через вход ChatGPT. Посетителям вход не нужен. Существующая старая версия игры на сервисном адресе сохранена.

Сохраняются случайные номера браузера и сеанса, день по Москве, тип события, мир, занятие и число решённых заданий. Имена, email, IP, user-agent, ответы и коллекции не отправляются. Cookie не используются. Случайные номера лежат в localStorage. Сеанс заканчивается через 30 минут без событий. Учтены Do Not Track и Global Privacy Control. Данные на сервере хранятся 90 дней. Подсчёт приблизительный: блокировщики, приватные браузеры, разные устройства и отсутствие сети влияют на цифры.


## Разные способы сбора карточек

Каждый набор из 9 карточек собирается тремя способами: примеры, «Деревья и палатки», «Фигудоку». Один способ даёт максимум floor(9 × 0.6) = 5 карточек. Для нового набора обязательно получить хотя бы одну карточку каждым способом: последние свободные места резервируются для ещё не использованных занятий. Ограничения независимы для каждого набора и мира. Источник каждой новой карточки сохраняется в itemSources профиля. При достижении лимита игра и начисление валюты продолжаются; интерфейс объясняет, какое занятие выбрать для новой карточки.

Старые карточки без сведений об источнике сохраняются и освобождены от новых требований задним числом: их количество уменьшает число резервируемых мест. Полностью собранные ранее наборы не сбрасываются. Повторно решённые головоломки по-прежнему не дают наград.

Проверка: `node --test tests/*.test.mjs`, включая перебор всех достижимых последовательностей сбора нового набора, лимиты всех трёх способов во всех мирах и наборах, резервирование последней карточки, загрузку и совместимость старых профилей.
