# Считай легко

Космический тренажёр сложения и вычитания двузначных чисел для детей.

Четыре миссии, 12 артефактов, звёзды и значки. Прогресс сохраняется в localStorage браузера на устройстве. Регистрация для игры не нужна.

## Запуск

Статический сайт без сборки. GitHub Pages: ветка main, папка / (root). Для локального запуска используйте любой HTTP-сервер.
