# Считай легко

Детский тренажёр сложения и вычитания двузначных чисел.

Три мира: космос (звёзды и 36 артефактов), собаки (Лорри — мальтипу, косточки и 36 пород), кошки (сосиски и 36 пород). Все тренировки и миссии смешивают сложение и вычитание. Каждый мир сохраняет отдельный прогресс в браузере. Старый космический прогресс сохраняется.

Статический сайт без сборки. GitHub Pages: main, / (root). Для локального запуска используйте HTTP-сервер.

Футбол: четвёртый мир с мячами и 36 карточками известных футболистов. На карточках игровые эмблемы с инициалами.

У каждого мира свой аватар. Доступны 12 значков за примеры, серии ответов, приключения и коллекции; прошлый прогресс учитывается.
