# Считай легко

Детский тренажёр сложения и вычитания двузначных чисел.

Три мира: космос (звёзды и 12 артефактов), собаки (Лорри — мальтипу, косточки и 36 пород), кошки (сосиски и 12 пород). Все тренировки и миссии смешивают сложение и вычитание. Каждый мир сохраняет отдельный прогресс в браузере. Старый космический прогресс сохраняется.

Статический сайт без сборки. GitHub Pages: main, / (root). Для локального запуска используйте HTTP-сервер.
